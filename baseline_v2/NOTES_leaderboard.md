# 리더보드 경향 정리 (2026-10-31)

## 1. 제출 결과

| 제출 | 모델 | 학습 오답 | LB |
|---|---|---|---|
| starter | 프레임 평균 DINOv2 + MPNet → MLP | 다른 에피소드 정답 1개, BCE | **0.3499** |
| minimal | starter와 같음 | 규칙 오답 8 + 다른 정답 3, listwise CE | **0.4260** |
| v2 | DINOv2 + SigLIP + MPNet, 프레임 순서·절 정렬 transformer | minimal + 역재생 영상 | **0.4391** |

무작위는 0.375다.

## 2. 로컬 검증 3종

같은 검증 에피소드 626개로 만든다. 오답만 다르다.

| 검증 | 오답 | 재는 것 | 문장 전용 모델 점수 |
|---|---|---|---|
| rule | `negatives.py` 규칙 오답 4개 (유형별 1개) | 기존 공통 검증 | 0.74 (문장만 봐도 풀림) |
| nn | MPNet으로 가장 비슷한 다른 에피소드의 진짜 정답 4개 | 장면 구분 | 0.34 |
| af_full | 규칙 오답 중 문장 전용 모델이 가장 정답 같다고 본 4개 | 같은 장면의 미묘한 차이 | 0.39 |

- 문장 전용 모델은 영상 없이 문장만 보는 MLP다. 0.375 근처면 문장 지름길이 막힌 것이다.
- af_full의 오답 선택(selector)과 지름길 확인(probe)에는 서로 다른 문장 전용 모델을 썼다.
- af_short는 probe가 0.68이라 쓰지 않는다.

## 4. 보이는 경향

| 관찰 | 근거 |
|---|---|
| 순서는 rule과 af_full이 맞힌다 | 두 검증 모두 starter < minimal < v2, LB도 같은 순서 |
| nn은 순서부터 틀린다 | nn은 starter > minimal, LB는 반대 |
| 크기는 셋 다 틀린다 | minimal → v2가 af_full로 +0.23, LB로는 +0.013 |
| af_full은 낮은 구간에서만 맞았다 | starter와 minimal은 LB와 ±0.02, v2는 0.20 차이 |
| 세 모델 모두 무작위 근처다 | LB 0.35 ~ 0.44 |

## 5. 해석

- v2의 로컬 이득이 LB에서 거의 사라졌다. v2가 배운 건 Train(PerceptionTest) 안에서만 통하는 것일 것이다.
- 테스트는 다른 벤치마크라 영상 분포도 다르다. 영상과 문장을 세밀하게 맞추는 구조일수록 이 차이에 약할 것이다.
- af_full도 결국 우리 규칙 생성기의 오답이다. 그러니 규칙 유형에 맞춘 개선은 LB로 옮겨지지 않을 것이다.
- minimal → v2가 거의 안 올랐다. 그러니 지금 병목은 모델 구조가 아닐 것이다.
- 세 모델 모두 무작위 근처다. 그러니 테스트에서는 아직 어떤 모델도 영상을 제대로 못 쓰고 있을 것이다.

## 6. 방향

- 로컬 검증은 순서 비교에만 쓴다. 점수 크기로 LB를 예측하지 않는다.
- Train 특화 학습이 문제인지 먼저 확인한다. 학습 없는 SigLIP zero-shot을 제출해, v2와 비슷하거나 높으면 학습이 Train에 과적합하고 있다는 뜻이다.
- 사전학습 지식에 더 기대는 쪽으로 간다. SmolVLM으로 선지별 likelihood를 비교하는 방식을 검토한다. 15분 제한부터 측정한다.
- 테스트 오답 유형을 직접 겨냥한다. 대회 예시(buttoning ↔ unbuttoning, "then sits down" 추가)는 동작 방향과 마지막 동작 추가 문제다.
- 유사 에피소드 정답 오답(nn 계열)은 보류한다. nn 검증이 LB를 못 따라갔다.
- 규칙 오답을 늘리기보다, 로컬 생성형 모델(T4 재현 가능)로 자연스러운 오답을 만드는 쪽을 검토한다.
